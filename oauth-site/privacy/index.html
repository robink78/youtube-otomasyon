Privacy Policy

This policy describes the owner-operated ImpossibleBrief video production application and website.

Google and YouTube data used

After the channel owner authorizes the application, it may use the YouTube Data API and YouTube Analytics API to identify the authenticated channel, upload videos, manage video metadata and playlists, read video/channel statistics, traffic-source data, audience-retention data, watch time, and subscriber gains or losses. The application requests only the YouTube scopes documented in its authorization flow.

Storage and processing

OAuth refresh tokens and client secrets are stored as encrypted GitHub Actions secrets for unattended production. They are injected only into authorized workflow jobs and are not committed to the source repository or intentionally written to logs or artifacts. Editorial metadata, upload identifiers, aggregate analytics, quality reports, and operational state may be stored in the private production repository. Generated videos and temporary access tokens may be processed transiently by GitHub-hosted runners and the relevant platform APIs.

Sharing and sale

ImpossibleBrief does not sell personal information or Google user data. Data is sent only to service providers required to operate the application, principally Google/YouTube and GitHub Actions, subject to their terms. The application is for the owner's channels and does not accept public user accounts.

Retention, deletion, and revocation

Operational records are retained while needed to prevent duplicate uploads, measure performance, and audit publications. The channel owner may revoke Google access at Google Account third-party connections. Revocation stops future API access; the corresponding GitHub secrets should then be deleted. To request deletion of locally retained application records, contact erdmyzn@gmail.com.

Security and contact

The application checks the authenticated YouTube channel ID before every write and blocks mismatches. No internet system can guarantee absolute security. Questions, access requests, or deletion requests: erdmyzn@gmail.com.
