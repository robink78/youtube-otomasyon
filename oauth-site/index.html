ImpossibleBrief

Impossible questions. Scientific answers.

ImpossibleBrief turns ambitious what-if questions into carefully sourced science videos. Each episode separates established knowledge, estimates, and speculation so an impossible premise does not become a misleading claim.

How the application uses YouTube

The private owner-operated production application uses YouTube APIs to upload videos, manage video metadata, verify the destination channel, and read channel/video analytics used to evaluate future editorial decisions. It is not offered as a public account-management service.
